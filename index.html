SoundWave

A music library web app built with Spring Boot. Browse songs and artists across five categories, save favourites, upload tracks and listen in a Spotify-style player that keeps playing while you move between pages.

  • Player in plain JavaScript with seeking (HTTP Range streaming), shuffle, repeat and media-key support
  • Sign up with a password or with GitHub (OAuth2); roles for visitors, users and admins
  • Two REST APIs documented with Swagger UI, search, sorting and paging
  • PostgreSQL with Flyway migrations, Docker build, 38 automated tests
